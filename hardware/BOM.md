## Схема подключения

```
18650 (3.7V)
  ├── TP4056 ← USB (зарядка)
  ├── MT3608 Boost → 12V ─── СОЛЕНОИД ─── DRAIN (IRLZ44N)
  └── AMS1117-3.3 → ESP32-3.3V

ESP32-C3:
  GPIO12 ─── 10kΩ ─── GND (pull-down)
  GPIO12 ─── GATE (IRLZ44N)
  GPIO8  ─── 220Ω ─── LED ─── GND
  GPIO9  ─── КНОПКА ─── GND (wake-up)

СОЛЕНОИД:
  [+] ─── 12V (MT3608)
  [-] ─── DRAIN (IRLZ44N)
  ║ 1N4007: катод→+12V, анод→GND (flyback)
  ║ 100µF: параллельно соленоиду
SOURCE (IRLZ44N) ─── GND (общая земля!)
```

**КРИТИЧНО**: GND всех компонентов — ОБЩАЯ.

## Логика питания

| Режим | Потребление | Автономность |
|-------|------------|-------------|
| Deep Sleep | ~5 µA | 12+ месяцев |
| BLE Advertising | ~30 mA | ~80 часов |
| BLE Connected | ~60 mA | ~40 часов |
| Соленоид (5 сек) | ~800 mA | 3000+ активаций |

**Пробуждение из Deep Sleep:**
- GPIO9 (кнопка) — EXT0 wakeup
- Таймер — периодически (раз в час)
- BLE — встроенный NimBLE wake-up
## Безопасность железа

- **Zero-Trust**: приватный ключ Ed25519 НЕ на устройстве. ESP32 хранит только публичный ключ. Физическая кража = 0 полезных данных.
- **Брутфорс-защита**: 3 неверные попытки → Deep Sleep 5 минут.
- **Одноразовый challenge**: HW TRNG (esp_random), новый при каждом чтении BLE.
- **Flyback диод (1N4007)**: ОБЯЗАТЕЛЕН параллельно соленоиду! Без него индуктивный выброс (~50-100V) убьёт MOSFET и ESP32.
- **Pull-down на затворе MOSFET** (10kΩ): чтобы замок НЕ открылся самопроизвольно при старте ESP32.

## Сборка прототипа (10 шагов)

1. Запаять AMS1117-3.3 на макетную плату, подключить к 18650 (через TP4056)
2. Настроить MT3608 на 12V (подстроечным резистором, проверить мультиметром)
3. IRLZ44N: Gate → GPIO12 через 10kΩ pull-down резистор к GND
4. Соленоид: [+] → 12V (MT3608), [-] → DRAIN (IRLZ44N)
5. SOURCE (IRLZ44N) → GND (ОБЩАЯ ЗЕМЛЯ!)
6. 1N4007: катод (полоска) → +12V, анод → GND (параллельно соленоиду)
7. 100µF конденсатор: [+] → 12V, [-] → GND (параллельно соленоиду)
8. LED: GPIO8 → 220Ω → анод LED → катод LED → GND
9. Кнопка: GPIO9 → кнопка → GND
10. Прошивка: `cd firmware/esp32_bike_lock && pio run -t upload`
11. Проверка: открыть nRF Connect на телефоне → найти "42_CAMPUS_BIKE_01"
12. Интеграционный тест: PWA → BLE → бэкенд → замок отпирается ✅
